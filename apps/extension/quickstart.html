Quick Start

Get started with ChatGPT Sync

Back up your ChatGPT Projects and chats locally, read them offline, and move them between accounts — in four steps. Everything stays in your browser.

How it works

  1. 1

    Capture a page

    Click Scan Page in the popup. ChatGPT Sync opens ChatGPT (if it isn't already), waits until you're signed in, then captures the current project, chat links, and visible messages.

  2. 2

    Back up everything

    Run Start Gentle Background Sync to open each chat with safe delays and cache its messages for offline reading. Use Sync Open ChatGPT Tabs for tabs you already have open.

  3. 3

    Read it offline

    Open the Offline Reader to browse cached projects, chats, and messages with no network — grouped by the account they came from.

  4. 4

    Move to another account

    Save to Browser Memory or Download JSON, switch accounts, then follow the guided restore checklist to rebuild the project safely.

ⓘ Local-first. ChatGPT Sync never asks for — or stores — your password, session cookie, access token, or API key.
